# 怒海求生 · 海上生存游戏

一款明亮卡通风格的 3D 海上生存游戏：驾驶小木船在无边大海中收集漂浮资源、升级船只、探索海域、应对天气变化，最终建成远洋巨轮通关。

**在线游玩**：https://yjj0339.github.io/nuhai/

## 玩法

- **航行**：`W/S` 升降帆，`A/D` 转舵（手机：左半屏滑动控帆转向，右半屏拖动转视角）
- **打捞**：靠近漂浮的木材、食物、淡水、金币、宝箱自动打捞（渔网等级越高范围越大）
- **生存**：饱食、水分持续下降，物资不足时会自动进食/饮水；风暴会持续损伤船体，木材会自动用于修船，靠岛时免费修复
- **天气**：晴朗 → 起风 → 浓雾 → 雷暴 循环变化，切换前有预警；雷暴天雨水自动补充淡水，但巨浪伤船
- **升级**：`E` 或右上按钮打开船坞，用金币+木材升级船帆/船体/货舱/船灯/渔网
- **探索**：右下小地图显示海图迷雾，探索度达标有金币奖励；发现新岛屿也有奖励；离起点越远资源越丰富、宝箱越多，风暴也越频繁
- **通关**：船帆 3 级 + 船体 3 级 + 木材 120 + 金币 150 → 建造远洋巨轮

## 技术

- 单文件 `index.html`（Three.js r158 本地 vendor，CDN 兜底），无构建依赖
- 程序化建模：帆船、岛屿、礁石、漂浮物、雨、浪花、海鸥
- 自定义着色器：天空穹顶（昼夜/星空/闪电）、海水（多层波浪 + 太阳高光 + 距离雾）
- WebAudio 合成音效（海浪环境音、打捞、雷声、升级）
- localStorage 自动存档，昼夜循环 150 秒/天

## 开发

开发源文件分块为 `game1~4.js` + `part1.html`，合并脚本：

```
node -e "const fs=require('fs');fs.writeFileSync('index.html',fs.readFileSync('part1.html','utf8').replace('/*__GAME_CODE__*/',()=>fs.readFileSync('game.js','utf8')));"
```
