# 怒海求生 · 海上生存游戏

一款明亮卡通风格的 3D 海上生存游戏（v4.4）：驾驶小木船在无边大海中收集漂浮资源、升级船只、探索海域、应对天气变化，最终建成远洋巨轮通关。

**在线游玩**：https://yjj0339.github.io/nuhai/

## 玩法

- **航行**：`W/S` 升降帆，`A/D` 转舵，`空格` 乘风突进（短时爆发加速，25 秒冷却；手机用右下冲刺按钮）
- **打捞**：靠近漂浮的木材、食物、淡水、金币、宝箱、漂流瓶自动打捞，金光一闪收入舱中（渔网等级越高范围越大）
- **捕鱼**：海上出现绿色涟漪的鱼群，把船停稳约 2 秒自动撒网收鱼
- **靠岛补给**：慢速停靠任何岛屿 1.6 秒即靠岸，免费补充食物/淡水/木材（每岛每天一次）
- **岛屿宝藏**：发现岛屿后，岛边浅滩藏着一次性宝藏箱（小地图金色菱形标记）
- **生存**：饱食、水分持续下降（天数越多消耗越快），物资充足时自动进食/饮水；木材自动修船，靠岛免费修复
- **天气**：晴朗 → 起风 → 细雨 → 浓雾 → 雷暴循环，切换前有预警；细雨天淡水自生；雷暴伤船但打捞+50%，风暴过后天边常挂彩虹
- **昼夜**：150 秒一天；夜晚星空、月亮、流星许愿、发光浮标，灯塔岛光束扫过海面
- **事件**：海豚伴航（打捞+25% 好运 60 秒）、漂流商筏靠近可交易、每天一封金色顺风信（金币+顺风加速）、远处鲸鱼喷水、漩涡会吸住船身要全速逃离
- **升级**：`E` 打开船坞，金币+木材升级船帆/船体/货舱/船灯/渔网/舵轮/瞭望台——帆面变大变金、灯光变亮、甲板货物增多、挂网、金线装饰随等级真实出现
- **目标与成就**：左侧目标卡 8 环任务链；`L` 打开航行日志：12 项生涯统计、14 项成就（带进度）、音效/音乐/画质设置
- **通关**：船帆 3 级 + 船体 3 级 + 木材 100 + 金币 150 → 建造远洋巨轮；通关后可继续**自由航行**

## 技术

- Three.js r158 本地 vendor（CDN 兜底），源码分块 `game1~4.js` + `part1.html`，node 拼接生成 `index.html`
- 程序化建模：顶点塑形流线船体、棕榈/岩峰/灯塔岛屿、九种精细漂浮物、海豚、商筏、鲸鱼；漂浮物模板克隆共享几何体
- 自定义着色器：天空穹顶（昼夜/星空/月亮/太阳）、海水（多层波浪+浪尖白沫+夜间色调+距离雾）；每帧零对象分配
- WebAudio 全程序化音频：海浪环境、独立雨声层、海鸥鸣叫、五声音阶环境音乐、雷声、事件音效
- 自适应画质：帧率过低自动降像素比；localStorage 自动存档（v4，兼容旧档迁移）
- 测试：playwright 无头 3 套回归（42 步）+ 加速浸泡测试 + 全自动通关验证 AI
