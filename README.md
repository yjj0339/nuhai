# 怒海求生 · 海上生存游戏

一款明亮卡通风格的 3D 海上生存游戏：驾驶小木船在无边大海中收集漂浮资源、升级船只、探索海域、应对天气变化，最终建成远洋巨轮通关。

**在线游玩**：https://yjj0339.github.io/nuhai/

## 玩法

- **航行**：`W/S` 升降帆，`A/D` 转舵（手机：左半屏滑动控帆转向，右半屏拖动转视角）
- **打捞**：靠近漂浮的木材、食物、淡水、金币、宝箱、漂流瓶自动打捞（渔网等级越高范围越大）
- **捕鱼**：海上出现绿色涟漪的鱼群，把船停稳 2 秒自动撒网收鱼
- **靠岛补给**：慢速停靠任何岛屿 1.6 秒即靠岸，免费补充食物/淡水/木材（每岛每天一次）
- **生存**：饱食、水分持续下降，物资充足时自动进食/饮水；风暴伤船，木材自动修船，靠岛免费修复
- **天气**：晴朗 → 起风 → 浓雾 → 雷暴循环，切换前有预警；雷暴打捞+50%、雨水补淡水；风暴过后天边出现彩虹
- **昼夜**：150 秒一天；夜晚星空+月亮+发光浮标，船灯自动点亮
- **事件**：海豚伴航（打捞+25% 好运）、漂流商筏靠近交易、远处鲸鱼喷水
- **升级**：`E` 打开船坞，金币+木材升级船帆/船体/货舱/船灯/渔网/舵轮（帆面随等级变大、灯光随等级变亮）
- **目标与成就**：左侧目标卡 8 环任务链；`L` 打开航行日志：统计、10 项成就、音效/画质设置
- **通关**：船帆 3 级 + 船体 3 级 + 木材 120 + 金币 150 → 建造远洋巨轮

## 技术

- Three.js r158 本地 vendor（CDN 兜底），源码分块 `game1~4.js` + `part1.html`，node 拼接生成 `index.html`，无构建依赖
- 程序化建模：顶点塑形流线船体、棕榈/岩峰岛屿、七种精细漂浮物、海豚、商筏、鲸鱼；漂浮物用模板克隆复用几何体
- 自定义着色器：天空穹顶（昼夜/星空/月亮/太阳）、海水（多层波浪+白沫+太阳高光+距离雾）
- WebAudio 合成音效与五声音阶环境音乐；localStorage 自动存档（v3）
- 测试：playwright-core 无头 16 步玩法回归（打捞/捕鱼/靠岛/交易/成就/风暴/结算）+ 关键画面截图评审
